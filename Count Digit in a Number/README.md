# 📊 Digit Counter in Java

This Java program calculates the **number of digits** in a given non-negative integer.

---

## 🧠 Algorithm

The program follows these steps:

1. Check the number is 0 or not (If n = 0 then return count = 1)  
2. If greater than 0 then  
3. Remove Last digit (n/10)  
4. Increase Count Value by 1 (count++)  
5. Repeat step 2 to 4  
6. Return the value of Count
